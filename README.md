# Tasmi AI

A muhaffiz in your phone: listens to your Quran tasmi, stops you on a wrong or skipped word and says the right word,
then keeps listening. Recite by safha, ruba, nisf, para, one ayah, or an ayah range (Madani 604-page mushaf).

**Open it in Chrome:** https://hamzakalolwala.github.io/Tasmi-AI/

- `site/` — the app (deployed to the `gh-pages` branch)
- `scripts/` — `words.py` (word lists), `divisions.mjs` (pages / quarters / juz)
- `test/` — `node --test test/*.test.js` (browser tests need Chrome + Playwright)

See `CLAUDE.md` for how it works and `site/NOTICE.md` for credits.
